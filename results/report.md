## 4. Reproducibility Scope

Byte equality is claimed only for `first_run.json`, `history.jsonl`, `metrics.csv`, `progress.svg`. They contain no timestamp and no runtime measurement. `multi_seed_results.json`, `multi_seed_metrics.csv`, `ablation_results.json` and `ablation_metrics.csv` embed `runtime_seconds` and `report.md` embeds those runtimes, so they are numerically reproducible but not byte-reproducible. `provenance.json` records the checkout state and is deliberately excluded from the claim.

The unit test `test_deterministic_and_runtime_artifacts_are_separated` runs the experiment twice and compares both classes of file, so the scope above is enforced, not merely asserted.

## 5. What the Tests Do and Do Not Establish

- `test_heldout_data_does_not_affect_selection` is a **scoped invariance check**: on this fixed synthetic dataset, inverting every held-out label and rewriting every held-out sentence leaves the recorded selection chain, versions and dev scores unchanged. It is not a mathematical proof of zero leakage for arbitrary code paths.
- `test_proposal_validation_*` exercises the injected-provider gate on synthetic proposals. It does not evaluate a language model; no LLM has been run in this repository.
- Passing tests confirm harness mechanics only. They are not confirmation of the research hypothesis.

## 7. Limitations

- Harness baseline only: no weights trained, no LLM called. `OpenWeightColabL4Stub` is an unwired boundary, not an integration.
- Synthetic 32-sentence lexical pool shared by every seed; no real-world data.
- Held-out split is 8 examples; conclusions must stay proportionate.
- `improvement` / `flat` / `regression` are operational labels, not significance results.
